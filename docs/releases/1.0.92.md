# Overlord 1.0.92

Free workers now review an early readiness stop before abandoning a scheduled
task. Actual reports repeatedly chose `needs_planning` because concrete actions
had not been executed yet, even with an owner-defined requirement and acceptance
checks. The added assessment distinguishes that situation from an actual missing
owner decision or an external prerequisite preventing useful work.

The review can admit a bounded pending plan or confirm the stop. It uses the
existing admitted free model pool and review routing preferences, with no new
provider, paid fallback or permissions. No project actions execute during review;
planning and review each have three schema attempts. An outage or invalid review
fails closed. Exhausted discovery cannot be renewed, and owner-defined acceptance
checks still override positive model judgments.

Reports include `readiness_review` with the proposed and final assessments.
This is a second model judgment, not proof of task relevance or test quality.
Existing schedules, owner task queues, settings and sessions remain preserved.
