# Overlord Bridge 1.0.26

- Free/local-model workers publish progress during their tool loop, including the task, concrete files and commands, concise worker notes, and actual completion or failure results.
- Writes and commands announce the next action before approval/execution. Routine file activity is batched at roughly eight-second intervals to avoid a message per read. All activity is also recorded for the console.
- Model prompts ask for concise explanations of what is being investigated or changed and why, while distinguishing plans from completed work. Detailed output remains collapsible.
- Progress text is bounded and uses the existing command-display secret redaction.

Offline tests cover progress before execution, concrete file/command names, worker notes, command exit status, and batching. Live Telegram behavior has not been qualified by these tests.
