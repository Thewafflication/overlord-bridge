# Overlord Bridge 1.0.9

- **Stale Claude usage:** an expired Claude CLI login made the live usage call fail
  (HTTP 401) and the bridge silently showed a weeks-old cache, e.g. "resets in
  September" at 100% used. A window whose reset time has passed now reads as
  rolled over, and `/status` names the expired login ("run `claude` once to
  refresh") instead of implying the numbers are current. The tray/console cached
  reading gets the same rollover handling.
- **Dotenv updates:** `set_env_value` accepts a BOM or an ANSI-saved `.env` instead
  of appending a duplicate key (which the loader then ignored) or raising.

855 offline tests pass (1 platform skip). No live provider calls were made.
