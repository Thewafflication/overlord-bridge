# Overlord Bridge 1.0.69

The desktop conversation renders fenced source blocks with language-aware syntax colors, a monospace background and inset margins. Whole-block tokenization handles multiline strings and comments while preserving tabs, line endings and literal Markdown/HTML. Unknown languages and large blocks remain plain code. Inline code stays separate.

Telegram now sends fenced source as native escaped pre/code blocks with language tags, enabling supported clients to highlight it. Long code is split into independently balanced HTML messages; log/output blocks retain their expandable presentation. Raw model HTML is never trusted.

Validation: native Tk tag/color/source-preservation smoke passed, focused UI/Telegram checks passed, and canonical syntax/inventory, wheel and offline checks passed (1,397 tests, one skip). Telegram native code markup follows https://core.telegram.org/bots/api#html-style; actual colors depend on the client and language.
