# Overlord Bridge 1.0.43

- Reject unknown top-level worker tool argument names and incorrect declared argument types before approval or execution. A misspelled source range now reports accepted parameters instead of silently reading the default page. File, command and plan value/path checks remain in place.
- Advertise exact parameter objects in tool schemas. Runtime keeps the existing cmd command alias.
- Identify empty HTTP-success replies in model diagnostics using finish-reason and token-count metadata, without logging reply content.
- Return recoverable errors for malformed formal argument JSON and non-object payloads. Error details and logs name rejected fields/types without echoing their values.

The observed 1.0.41 run accepted a startup plan and made real queue edits, but still sent malformed Python requests. Inspection also found that ignored read parameters could silently change what source was returned. The new boundary makes these tool-contract failures explicit. GUI feature work remains on the local continuation branch, separate from this harness release.

The worker independently pushed v1.0.42 from its GUI branch while source/runtime versions still declared 1.0.41, and the existing workflow automatically published it. That tag and its assets are preserved as a prerelease. This stable harness release uses 1.0.43 to avoid reusing its version. Release staging now checks the requested version against pyproject.toml and FALLBACK_VERSION before downloading build tooling, staging files or signing.

Confirmed file-change metadata now has its own bounded ledger across context trimming and progress checkpoints, so later discovery cannot erase the record of earlier edits. Completion review receives that ledger and is instructed to request evidence for missing functionality rather than infer that unshown code does not exist.

Validation: canonical `python tools/check.py all` passed (syntax/inventory, wheel build, 1,249 tests passed and one skipped). Focused worker/runtime/release-guard checks passed (212 tests).
