# Overlord 1.0.96

Live pilot logs showed that the configured larger NVIDIA Super model returned
HTTP404. The nemotron aliases and known saved legacy Super ID now resolve to
nvidia/nemotron-3.5-super-vl-120b-a12b, listed by NVIDIA's current public catalog
and API reference. The existing NVIDIA provider and account remain in use; no
new paid provider, opt-in, daily limit or output budget is added.

The current Super model is recognized by hard-task reasoning preferences. It
uses documented low reasoning effort within the free worker output budget, and
its different provider IDs are treated as the same reviewer family. This fixes
an unavailable preferred route, not a guarantee of model correctness.

The improvement ledger retains the failed live pilots and the measurable
regressions, release proofs and actual outcomes. Passing owner checks and local
commits remain required; unverified model finishes are not counted as delivery.
