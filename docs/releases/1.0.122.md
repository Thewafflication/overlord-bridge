# Overlord 1.0.122

Worker context fitting now prioritizes recent paired tool exchanges over
optional duplicated action metadata for older exchanges as well as the newest.
If both pages cannot fit intact, an older source page is structurally shortened
with its exact continuation cursor. Paired calls/results, chronology, original
task/preloads, model plan, mutation evidence and unresolved feedback survive.
Non-source exchanges that still cannot fit are omitted as complete groups.

The 1.0.121 live capture showed Silver alternating between CMakeLists.txt pages
1 and 167. A 53,087-character replay assembled from those actual exchanges and
their recorded checkpoint metadata retained only one source result under the
48,000-character bound. With this change it retains both in 46,834 characters.
The older page is explicitly shortened with continuation at line 211, column
71; the newest page remains intact. The pinned prefix is byte-for-byte equal.

Regression tests cover intact and shortened older pages alongside pinned plans,
mutations and completion feedback. This repairs a demonstrated evidence-eviction
mechanism. It does not establish that every repeated read has this cause, that
the model uses all supplied evidence correctly, or that live delivery improved.
