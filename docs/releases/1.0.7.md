# Overlord Bridge 1.0.7

Hardening release from a full codebase audit. No new features.

## Security

- Worker reports now redact Bearer/Basic credentials, prefixed `*_API_KEY` /
  `*_TOKEN` assignments and quoted JSON secrets before Telegram or disk.
- The MCP email tool refuses off-limits attachments (`~/.ssh`, `.aws`, `.env`, ...).
- MCP dispatch rejects `session` values that could name a path; resume-timer names
  can no longer inject systemd unit directives.
- The permission gate catches bare dot-directories (`cat .ssh/config`); local-agent
  command/path denial understands Windows separators and home paths.

## Reliability

- `/model`, `/effort` and `/brain` no longer block the main loop (and `/stop`)
  while a turn runs; command-handler failures no longer shut the bridge down.
- `/context` and `/compact` with trailing text are no longer sent to the model.
- Permanent Telegram `BadRequest` errors are not retried.
- Codex: real error text preserved, no phantom turn after a rejected start,
  `/effort` no longer claims an ignored value; both brains keep the saved session
  pin through CLI/app-server outages.
- Dispatch files are read as UTF-8, tolerate in-progress writes, and rejected files
  are reported to the owner. Tasks beginning with `-` are no longer parsed as flags.
- `.env` / `AGENTS.md` are read as UTF-8 (BOM and ANSI tolerated).
- Also: pty leak in shared-job injection, MCP crash on non-object JSON, one failing
  engine probe blanking the gas gauge, corrupt token ledger, `1000k` display,
  unlocalizable reset dates, free-model tool-support check.

## Validation

848 offline tests pass (1 platform skip), up from 346. No live provider calls were
made; live qualification and WSP dispositions remain open as in 1.0.6.
