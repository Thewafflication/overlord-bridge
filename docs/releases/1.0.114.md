# 1.0.114

Fix a worker context-loss loop that could prevent moving from source inspection
to edits. When a newest parallel source batch exceeded the remaining request
budget, history fitting previously dropped all its results, retained only action
metadata and allowed the same reads again. Now fitting prioritizes that batch
and, where needed, shortens each source page with exact continuation cursors.
Calls and replies remain paired; task instructions, plans, mutation evidence and
completion feedback remain protected. Source pages exceeding the transport cap
also retain structured content and pagination instead of a serialized JSON tail.

A controlled four-file reproduction changes from zero retained source replies
to four. An integration worker then edits an existing file and validates it.
Tests cover source transport, request fitting, fallback results, mid-line cursors
and CRLF. These prove the harness repair; a later live cohort must establish
whether project deliveries improve. Existing project toolchain blockers and
model repetition may still require further work.
