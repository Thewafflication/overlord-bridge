# Overlord Bridge 1.0.65

Free-model project dispatch now preserves the original owner request alongside subordinate dispatcher notes. Milestone continuation requests retain their implementation objective instead of silently becoming read-only surveys.

Workers preload allowed project orientation documents, including HANDOFF.md, AGENTS.md, README.md, docs/README.md and ROADMAP.md, after explicit file hints. Bounded excerpts retain document beginnings so status warnings and documentation links survive context trimming. Workers are instructed to reconcile historical roadmaps with current requirements, tests, recent history and source before selecting a next deliverable.

Context trimming replaces old generated checkpoints instead of nesting them. Duplicate read/list/search protection resets only for requests whose exchanges were actually evicted, preventing repeated trims from authorizing the same retained reads indefinitely. Model-authored planning findings are surfaced as worker assessments while routine file activity remains batched.

Validation: full checks passed syntax/inventory validation, wheel build and 1,387 tests with one skip. Final targeted checks passed 161 tests, including malformed-call handling. Regression coverage includes owner-intent preservation, pinned document headings, checkpoint replacement and retained-read duplicate protection. The previously looping live WCRT worker was stopped; this release does not claim a successful live retry of that task.
