# Overlord Bridge 1.0.10

- **Free-model chat brain** (`/brain free`): text-only chat over NVIDIA NIM and
  opt-in OpenRouter `:free` models, with persisted per-provider rpm/daily budgets,
  429/`Retry-After` cooldowns and fallback across models.
- **Model/effort switcher:** `/model` and `/effort` show the current model and effort
  and offer Telegram buttons (Claude aliases, Codex's native catalog, free models,
  per-brain effort levels), with a one-tap hop between the two settings.

906 offline tests pass (1 platform skip). No live provider calls were made, so the
free-tier default limits are unverified against the live services.
