# Overlord 1.0.123

Planning-context fitting now refines a skipped budget interval before rejecting
protected task evidence. The coarse 1 KiB reduction could jump from an oversized
request to a context budget below the protected floor, overlooking a valid
request between them. The bounded refinement preserves the original task,
preloads, current plan, mutations, unresolved feedback and outer instructions.
Genuinely oversized protected content still fails explicitly.

The post-1.0.122 cohort contained two planning-context failures. A reconstruction
from the KerTeX execution capture, terminal continuation and source-defined
planning prompt reproduces the prior rejection. With this repair it fits in
47,918 characters under the 48,000-character bound, with the pinned prefix and
current plan unchanged. This is a reconstructed checkpoint, not a captured
planning HTTP request or a successful project delivery.

Two regressions exercise escaped plans at this boundary; both failed before the
repair. Coverage also retains explicit failure for truly oversized instructions.
The live cohort still has zero acceptance-verified deliveries; this release
repairs a demonstrated fitting defect, without claiming improved model quality.
