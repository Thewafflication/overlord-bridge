# Overlord Bridge 1.0.8

Includes the hardening and regression coverage from 1.0.7, plus a cross-platform
fix discovered by release CI: updating a dotenv setting now preserves existing
CRLF or LF line endings on both Linux and Windows.

The signed WPM package is verified by the release workflow. No live provider
calls were made; live qualification and WSP dispositions remain open as in 1.0.6.
