# Overlord Bridge 1.0.61

Selecting a slash command now offers tappable argument choices in Telegram. /brain, /status, /tokens, /permissions and /work provide fixed option buttons; /model and /effort provide the engine's full catalog, with seven entries per page and Next/Previous navigation. Model catalogs are no longer limited to the first seven choices in the real Telegram picker.

Selections queue the same exact commands as typed input, preserving command validation, active-turn restrictions, permission handling and persistence. Callback data contains short opaque tokens and indices, supporting long Unicode model IDs within Telegram's 64-byte callback limit. Pickers are owner-only, bound to their message, expire after ten minutes, and cannot be replayed after selection, cancellation or replacement. Brain switching clears old choices. Pending AI questions remain separate.

Telegram sends a selected slash command immediately (https://core.telegram.org/bots/features#commands); bots do not receive the user's draft keystrokes. The supported workflow is select command, then tap its argument button. Free-text tasks, prompts and other arbitrary arguments can still be entered normally.
