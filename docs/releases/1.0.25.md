# Overlord Bridge 1.0.25

- Free project workers no longer stop at 30 agent steps by default. They continue until the model completes the task, the worker is cancelled, or a provider/request failure prevents further work.
- `OVERLORD_FREE_WORK_STEPS=0` disables the cap; a positive value remains available as an explicit limit. Existing explicitly configured positive limits remain in effect until changed to zero.
- A free worker reaching an explicit step cap is reported as incomplete with a nonzero exit status, rather than as successfully finished.
- Unlimited runs yield between steps so cancellation remains responsive. Provider budgets, approval rules and duplicate-call protections remain in effect.
- Worker completion text stays visible while tool diagnostics, session metadata, and agent-step counts use expandable Telegram logs.

Offline tests cover completion beyond 30 steps, explicit cap exhaustion, and cancellation beyond 30 steps. Live provider behavior has not been qualified by these tests.
