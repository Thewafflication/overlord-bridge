# Overlord Bridge 1.0.36

- Free project workers now request an 8,192-token response budget, configurable with OVERLORD_FREE_WORK_MAX_TOKENS (64–32,768). Model-specific payload caps still apply. Ordinary chat keeps its separate OVERLORD_FREE_MAX_TOKENS default of 2,048. The override is per request and does not mutate the shared chat pool.
- search_file accepts a file, directory or omitted path (project root), with an optional filename pattern. Results include paths and 1-based line numbers, scan/skip counts and truncation metadata.
- Directory searches reuse file-discovery exclusions, scan at most 500 candidate files, limit individual reads to 512 KiB and searchable aggregate content to 8 MiB, and bound match output. Binary, oversized and excluded artifact/log/media files are skipped; incomplete search scope is reported so workers can narrow it.

The observed turn repeatedly exhausted the shared 2,048-token response limit across multiple providers and had to be stopped. It also sent directory searches to the previous single-file tool. No new GUI edits were made on its saved branch; commit adbb751 on codex/gui-worker-attempt-20261021 remains available for continuation.

Full offline validation: syntax checks and wheel build passed; 1,183 tests passed and one skipped. Regressions cover separate per-request budgets/model caps, directory/root search, filename filters, generated-directory exclusions and scan/output bounds. Live behavior with the larger budget still needs verification after updating.
