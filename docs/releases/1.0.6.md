# Overlord Bridge 1.0.6

This release publishes the latest verified OVL-M02 implementation checkpoint.
The increment remains in progress; release publication does not establish live
provider qualification or complete WSP conformance.

## Changes

- More reliable Claude/Codex usage handling and paired offline workflow tests.
- Explicit question replies, whole-set review/edit/cancel, and responsive Codex
  approval handling with protection against delayed requests after turn completion.
- Exact session permission grants, revocation race protection and bounded local
  decision auditing; approval fails closed when an audit write fails.
- Durable conversation checkpoints, native compaction and bounded stop controls.
- Opt-in OpenRouter free-model workers with catalog validation, zero-price request
  ceilings and provider fallback disabled.
- Opt-in local LLM model routing, manual overrides and visible native Codex
  catalog filtering. Catalog visibility does not prove account entitlement.
- WSP 1.4.0 baseline and controlled requirement inventory, plus reproducible
  lint/build/test checks and independent Windows/Linux CI.

## Validation and remaining work

The implementation checkpoint passed 346 offline tests with one platform skip,
syntax checks, wheel build and hosted Windows/Linux checks. Tests made no live
provider model calls. Claude context snapshots remain disabled by default pending
provider cost qualification. Routing and free-worker pilots require explicit
configuration. Shared-terminal parity, persistent permission scopes, structured
context reconciliation, additional free providers, live acceptance and WSP
disposition reviews remain open in the
[increment progress record](../plans/ovl-m02-progress.md).

Release assets include the WPM package, repository index, public verification key
and SHA-256 checksums. Use the release workflow's verification result to establish
whether the package was signed; publication alone is not a signature claim.
