# Overlord Bridge 1.0.23

- Routine-command approval is now a distinct `safe` bridge permission level, alongside `ask` and `full`. Settings → Permissions selects and persists the level; `safe` remains the default.
- `/permissions level ask` and `/permissions level safe` select the running level and clear prior exact grants and timed access. `/permissions full 10` remains the temporary full-access command. `/permissions` and startup messages report the level.
- `OVERLORD_PERMISSION_LEVEL` overrides the legacy `OVERLORD_AUTO_APPROVE` setting. Existing configured full approval is migrated when an explicit level is absent. Invalid configured levels fall back to `ask`.
- Levels are mutually exclusive. Off-limits checks, auditing, timed grants, and native engine restrictions remain in force. Configured `full` persists until changed; Telegram full-access windows expire on their deadline.

Offline tests cover level selection, configuration migration, UI saving, live settings reload, grant clearing, and routine-command approval behavior. Live Telegram behavior has not been qualified by these tests.
