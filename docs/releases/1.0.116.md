# Overlord 1.0.116

An exhausted discovery proposal now receives the same independent readiness
review as other early stops. Previously, another discovery assessment could
bypass review and become needs_planning without an owner question. This was
observed in TinyPP run 40d953bc0d9e41a88ecf63c97e99624b.

The reviewer can select defined technical work or confirm a concrete stop.
Repeated discovery receives bounded schema corrections; it cannot renew the
six-action allowance. The harness preserves the model's actual proposal rather
than manufacturing a missing owner decision. Unavailable or invalid review
still leaves the run incomplete. Permissions and acceptance remain authoritative.

A worker regression first fails on the previous implementation, then exercises
six discovery actions, reviewed admission, a real edit and an assertion command.
It demonstrates repaired control flow, not an accepted project delivery.
