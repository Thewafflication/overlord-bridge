# Overlord 1.0.93

A scheduled Python environment repair issued `tskill python`, terminating the
bridge itself. Worker command checks now refuse known process-termination verbs
and direct Python os/signal kill calls before approval or launch. Read-only
process inspection remains allowed. This is a bounded static check, not isolation
against arbitrary indirect scripts or aliases.

A separate Mypal run crashed with "Protected planning context cannot fit".
Planning request fitting errors now stop the worker as incomplete and retain its
handoff instead of losing that continuation to a crashed outcome. The change does
not discard protected owner instructions or claim the oversized task completed.

Schedules, owner acceptance queues, sessions and free-mode settings are retained.
