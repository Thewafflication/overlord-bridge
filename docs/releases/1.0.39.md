# Overlord Bridge 1.0.39

- Bound free-worker history before every request, retaining original task/instructions, recorded action context and complete recent tool exchanges. Long discovery no longer sends an ever-growing transcript to fallback models. The 48,000-character guard is conservative history trimming, not a model-specific tokenizer.
- Add a progress checkpoint after extended discovery without a successful file edit. The model decides whether to implement, investigate a specific blocker or conclude a read-only task; the checkpoint does not force edits.
- Retain command evidence separately from later reads, with step order for checking that validation covers final edits.
- Failed commands now include shell/interpreter details and practical recovery hints. Worker instructions require staging explicit paths while preserving pre-existing changes.
- Canonical wheel checks clear generated build/lib staging before packaging, preventing modules removed by a branch switch from leaking into local wheels.
- Free-model pool exhaustion reports incomplete with diagnostics and preserves existing edits/commits, rather than reporting a worker crash or success.

The observed 1.0.38 run spent 45 steps on discovery, repaired existing GUI test failures, passed the existing suite and canonical checks, and committed. It then exhausted its free pool; one fallback rejected the oversized transcript. No final completion review or publication occurred. The worker also swept pre-existing generated/development files into its commit; they were removed from tracking while preserving the files. GUI changes remain on the local continuation branch and are not included in this release.

Validation: canonical offline syntax checks and wheel build passed; 1,203 tests passed and one skipped. The rebuilt wheel was inspected and contains neither GUI-only chat module. Regression coverage includes long worker context, complete parallel tool exchanges, oversized batches, progress checkpoints, command evidence retention, failed-command recovery, pool exhaustion and stale build staging.
