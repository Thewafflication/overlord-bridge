# 1.0.113

Free workers now receive twelve repeated-observation windows rather than three
before yielding, retaining twelve-action coaching checkpoints (typically 156
rather than 48 actions with an unchanged checkout). Productive work can continue
beyond this: this threshold applies to consecutive repeated-observation windows,
not total run length. Explicit step limits, cancellation and actual blockers
still apply.

Initial plans and checkpoint coaching ask for smaller subtasks: one concrete
action with an observable check, followed by its evidence. Overall acceptance
and owner-file protection remain required.

Reports retain cumulative confirmed file mutations, distinct successful command
results, new successful observations, new failure diagnostics and repository
change checkpoints. Model-reported completed steps are separate unverified claims.
Outcome summaries aggregate these partial counters and disclose measured-run
coverage; legacy reports are unmeasured, not evidence of zero progress. Partial
activity is not an accepted subtask or a verified delivery.
