# Overlord Bridge 1.0.21

- Every bridge brain and project worker receives runtime host-platform context. On Windows, owner-facing instructions use PowerShell, Windows paths, and verified Windows entry points.
- Models are instructed not to assume Bash, WSL, Git Bash, or Unix utilities are installed, or recommend executing `.sh` scripts directly on Windows. Project scripts should be inspected to find a Windows-compatible route.
- Free/local worker prompts describe the actual cmd.exe command surface and explicit PowerShell invocation. Current host context takes precedence over Linux documentation examples and stale conversation history.

Offline tests verify platform-specific context, stale-history grounding, brain construction, and worker execution. Live provider responses have not been qualified by these tests.
