# Overlord Bridge 1.0.68

Worker planning checkpoints now use a fresh planning conversation. The bounded execution history is supplied as read-only evidence instead of live assistant/tool dialogue. This keeps earlier command requests from competing with the checkpoint's plan-only instruction. Rejected replies are supplied to the next repair attempt, and wrong tool calls or missing arguments receive specific diagnostics instead of a misleading missing-array error. Existing plan validation and the prohibition on executing project actions during planning remain in force.

Validation: free-worker suite passed 161 tests before the added isolation regression; targeted checkpoint regressions passed. Canonical checks passed syntax/inventory, wheel build and 1,392 tests with two skips. A real isolated queue worker reproduced a failure, fixed the implementation, passed three unchanged tests and made local commit c1fd7d3 after continuation from a rate-limited first attempt. Independent verification confirmed all three tests and only the implementation in the commit. This bounded evaluation does not establish that every scheduled project now completes.
