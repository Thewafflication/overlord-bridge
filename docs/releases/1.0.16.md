# Overlord Bridge 1.0.16

- WPM installation stops the installed Overlord bridge, console, setup window and worker descendants before replacing files. Only processes belonging to that installation are targeted. A bridge that was running is restarted after installation; an idle installation stays idle.
- Failed upgrades preserve or restore the previous installation and restart it if it had been running. Staging failures no longer delete the existing install. Uninstall also stops installation processes before removal.
- The Windows console opens maximized. A Stop Overlord toolbar button and File menu action use the bridge shutdown path, which closes the tray and console. Closing or hiding the console still leaves the bridge running.

Backward-compatible 1.x release. Tests cover process targeting, worker descendants, hidden restart with spaced paths, failed staging with and without a running bridge, and console shutdown delivery.
