# Overlord Bridge 1.0.60

- Expand live OpenRouter free-model discovery from three to sixteen models. Prioritize vendor diversity, then retain additional models from the same vendor. Continue requiring explicit :free IDs, live zero input/output prices and a zero-price routing ceiling; worker calls still require tool support.
- Add Google Gemini through its OpenAI-compatible endpoint to free chat and the shared free-worker completion pool. Supported text models: Gemini 3.5 Flash-Lite, 3.1 Flash-Lite, 2.5 Flash and 2.5 Flash-Lite. Request pacing defaults to 5/minute and 20/day across Gemini models, with existing cooldown/fallback behavior.
- Add Gemini key testing and an explicit enable checkbox to Settings. Use a Google AI Studio project without billing to stay in the free tier. Overlord cannot inspect the project's billing tier; a paid project can incur charges. Gemini stays disabled until enabled and keyed.

Free web chats are separate from API access. Grok and Claude APIs are priced services; ChatGPT's free plan does not grant a free OpenAI API allowance. They are not added as falsely free API fallbacks. OpenAI GPT-OSS remains available through NVIDIA. OpenRouter automatically includes these vendors if they later publish qualifying free IDs.

Setup: Settings > API keys > Google Gemini, create a key at https://aistudio.google.com/apikey using a project without billing, test it, enable Gemini and save. Environment alternatives: OVERLORD_FREE_GEMINI_API_KEY (or GEMINI_API_KEY), OVERLORD_FREE_GEMINI_ENABLED=1. Custom OVERLORD_FREE_MODELS lists must include gemini:model IDs. No existing keys or sessions are changed by installation.

Sources checked October 28, 2026: Google pricing https://ai.google.dev/gemini-api/docs/pricing and compatibility https://ai.google.dev/gemini-api/docs/openai; xAI pricing https://docs.x.ai/developers/pricing; Anthropic pricing https://platform.claude.com/docs/en/about-claude/pricing; ChatGPT pricing https://learn.chatgpt.com/docs/pricing.
