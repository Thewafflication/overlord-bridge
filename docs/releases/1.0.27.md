# Overlord Bridge 1.0.27

- Free-mode conversation favors brief, relevant replies and accepts newly supplied context and corrections.
- Successful fallback diagnostics and automatic token footers no longer clutter free-mode replies. Token usage remains available through `/tokens`.
- New worker reports are persisted in free chat context as worker-reported claims, so follow-up questions can use their results.
- Replies over 80 words receive one tool-free editing pass to remove repetition and unsolicited offers while preserving requested detail. Editing shares free-model budgets, has a 30-second deadline, and retains the original answer if unavailable.

Validation: full lint and wheel build passed; 1,124 offline tests passed and one skipped. Live Telegram regression exchanges confirmed concise replies, correction handling, and absence of unsolicited worker offers and diagnostic messages. The typing indicator was also observed remaining active during response generation.

See [live conversation validation](../free-mode-message-validation.md) for prompts, replies, and limitations. Editing may add an extra free-model request and up to 30 seconds of latency for long replies.
