# Overlord Bridge 1.0.30

- Free project workers can select PowerShell directly, preserving multiline code, variables and quotes without nested cmd.exe escaping.
- Added run_python using the bridge interpreter, avoiding missing Python PATH entries and Windows Store aliases. Python execution uses command restrictions and free worker approval.
- File reads support start_line and line_count so workers can inspect any part of large source files without shell pipelines.
- Windows worker instructions explain shell dialects, direct file reads, interpreter selection and failure diagnosis.

Validation: regression tests execute real multiline Python and Windows PowerShell commands, verify line ranges and command approval.

Full offline validation: syntax checks and wheel build passed; 1,150 tests passed and one skipped. Provider model behavior has not been live-qualified for this release.
