# Overlord Bridge 1.0.11

- **OpenRouter is the default free provider:** `openrouter:free` discovers the best
  zero-priced chat models from the live catalog at start-up (with a fallback list),
  and is on once a key is set (`OVERLORD_FREE_OPENROUTER_ENABLED=0` opts out).
- **Free-model status:** `/status`, `/status all` and the Tk console now show key
  state, each model's availability and per-provider budgets, including when the
  free brain is on standby.
- **Start-up splash (Windows):** stage, progress and live log tail until Overlord is
  online; stays up with the error if start-up fails. `OVERLORD_SPLASH=0` disables it.
- **API keys window:** tray menu "API keys…" or `run-windows.ps1 -Setup` to paste,
  test and save NVIDIA/OpenRouter keys; a running Overlord reloads them live.

958 offline tests pass (1 platform skip). No live provider calls were made.
