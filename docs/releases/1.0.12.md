# Overlord Bridge 1.0.12

- **Free models can work on projects:** `/work <project> <task>` starts a worker
  (`"brain": "free"`) that lists/reads/writes files and runs commands inside one
  project folder, fed by the free-model pool so it shares the chat's rate limits,
  cooldowns and fallback, and waits out short limits. `/work`, `/work status` and
  `/work stop` list, inspect and cancel.
- **Operator approval:** writes and commands ask on Telegram by default
  (`OVERLORD_FREE_WORK_APPROVAL=all|commands|none`); actions the built-in denial rules
  forbid never reach the phone.
- **Workers where projects live:** the workspace folder and `OVERLORD_PROJECTS_ROOT`
  are allowed worker roots, so dispatch works outside `~/Projects` (for example
  `source\repos`).
