# Overlord Bridge 1.0.29

- `/stop` cancels background project workers as well as the active chat turn, clears their pending approvals, and terminates owned Windows command process trees. Workers report when cancellation completes.
- Added regression coverage for cancelling a worker waiting on approval, terminating a real command subprocess, and passing `/permissions full 60` from Telegram normalization to the permission gate while a worker waits.

Validation: lint and wheel build passed; 1,146 tests passed and one skipped. After restarting the deployed bridge, the owner confirmed that `/permissions full 60` enables the timed grant in Telegram. The rejected command was not reproduced in the current parser; the previous process predated the installed source updates.
