# Overlord Bridge 1.0.19

- Natural-language project requests in the free brain can now dispatch the existing tool-enabled worker against configured local checkouts. Requests such as “Code review the silver searcher please” offer project dispatch instead of being instructed to deny filesystem access.
- Project selection uses the LLM tool contract and configured folder names. Unlisted paths and invalid dispatch arguments are rejected.
- Review instructions request actionable findings with file/line evidence and no edits. Existing worker approval controls and `/work` commands remain available.

Backward-compatible 1.x maintenance release. Offline regressions cover natural-language review dispatch, argument validation, free-model fallback and bridge turn handling. Live Telegram/provider behavior has not been qualified by these tests.
