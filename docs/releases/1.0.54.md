# Overlord Bridge 1.0.54

- Drain free/local worker command stdout and stderr concurrently into bounded buffers instead of accumulating all output in memory before shortening it. Noisy commands retain their latest complete lines and final diagnostics without growing capture memory with total output.
- Preserve captured output when command cleanup leaves output pipes open. Report the timeout and pipe-cleanup failure alongside the partial diagnostics instead of replacing them.
- Mark omitted output and discard an incomplete leading line after byte-buffer truncation, avoiding broken Unicode and credential fragments whose redaction prefix was omitted. Normal character limits and redaction still apply. A single line longer than the byte buffer is omitted until a newline arrives.

Regression coverage includes a real command writing over 4 MiB to each stream, bounded buffer storage, Unicode boundaries, partial credential lines, process-tree cleanup, and a simulated pipe that never closes after timeout.

Validation: canonical syntax/inventory, wheel build and full suite passed with 1,315 tests and one skip. All command capture regressions passed, including preservation of partial stdout/stderr after timeout.

Installed verification: Windows and Linux release CI passed. The signed package verified and installed successfully, and its worker module matches the tested source. An installed-worker command generated 4 MiB on each stream and returned the final Unicode diagnostics with truncation markers in 79/78 characters respectively.
