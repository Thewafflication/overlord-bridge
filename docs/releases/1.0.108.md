# Overlord 1.0.108

Initialize UTF-8 console input/output and PowerShell pipeline encoding at Windows
launcher startup, before Python or worker commands. Hidden/detached launches
previously left a legacy code-page context for native grandchildren while the
worker decoded UTF-8. This reproduced WSH frontend-process Unicode failures:
inherited console passes, no-window and hidden-new-console both fail unchanged.
Calling the repaired real launcher makes both modes pass without changing WSH
source, expected hashes, test assertions or CTest acceptance commands.

Native regressions invoke the real launcher in help mode before any settings
read or bridge start, capture a UTF-8 child through .NET, and retain failing legacy
controls. This prevents a passing developer-console audit from masking the
observed service launch-context failure. Other model planning loops and protected
context fitting remain separate issues. No new project delivery is claimed.

Preserve17 schedules: four defined-goal active schedules at60seconds and13
intentional pauses; free mode, owner queues and sessions remain. Pydecipher's
four original hashes are unchanged and recovery remains required.
