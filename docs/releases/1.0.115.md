# Overlord 1.0.115

Free-worker reviewers must supply the specific question for the owner when
confirming a `needs_planning` stop. A TinyPP review previously confirmed that
stop while reporting a ready task and no missing owner decision. The planner
now requests a corrected decision within its existing review budget and
includes a confirmed question in the worker report. The schema-retry example
also stops suggesting a default readiness state.

A scripted worker regression exercises the contradictory stop, a corrected
review, and a subsequent file edit. Production delivery still requires the
project's own acceptance checks.
