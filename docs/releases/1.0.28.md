# Overlord Bridge 1.0.28

- Claude, Codex and free mode receive the same canonical owner instructions. Durable shared memory carries preferences, project decisions, unfinished work and labelled worker reports between engines. Natural-language remember/update/forget operations use a shared store outside the replaceable Windows installation.
- `/context` reports fresh session/model-matched observations and monitoring thresholds. Configurable warnings default to 75%; optional automatic compaction defaults to an 85% threshold and runs between turns after a checkpoint. New installations must enable automatic compaction explicitly.
- Free mode can compact with a tool-free summary, preserving the latest exchange and a transcript backup. Native Claude/Codex compaction requires completion evidence. Context displays distinguish native token observations from free mode's local history budget.
- Selected Codex models are passed explicitly on turns, preventing resumed-session defaults from overriding a model change.

Validation: lint and wheel build passed; 1,143 offline tests passed and one skipped. Live Telegram tests verified free-mode save, Codex update, and free-mode deletion of the same temporary memory note. Live automatic free-mode compaction reduced retained history from 90.5% to 8.6% of its budget. Claude's live memory test was blocked by its session usage limit. Native automatic threshold compaction was not forced live.

See [shared context](../shared-context.md) and [context monitoring](../context-monitoring.md) for configuration, measurements and limitations.
