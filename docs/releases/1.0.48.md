# Overlord Bridge 1.0.48

- Expand bounded worker plan memory from 12 to 24 steps and from 1,000 to 4,000 explanation characters. Preserve findings for multi-part implementation and integration tasks within the existing 48,000-character input budget.
- Share limits between the tool schema and runtime validator, and state them in progress-planning instructions.
- Distinguish wrong plan shape from empty/oversized arrays. Report actual step/character counts for limit errors without submitted values, allowing targeted repair instead of an ambiguous combined error.

The observed 1.0.47 run repaired an overlong explanation once, then ended incomplete at step 48 after repeated plan-shape/size failures. It made no edits. This release gives its model-authored working state more room while retaining explicit bounds and strict type/status checks. It does not establish GUI feature completion.

Validation: canonical `python tools/check.py all` passed (syntax/inventory, wheel build, 1,282 tests passed and one skipped). Detailed progress-plan and size/privacy regressions passed; pre-commit configuration and release-version validation passed.
