# Overlord Bridge 1.0.20

- `/permissions full [minutes]` enables timed full access for bridge approval requests, including project workers. The default is 10 minutes; durations from 1 to 1440 minutes are accepted.
- Existing pending approval requests are released. Each new action checks a monotonic deadline; expiry restores normal approval behavior. Permanent configured auto-approval is disabled when a timed window is granted.
- `/permissions` shows remaining time. `/permissions revoke all`, session reset, and process restart clear the window.
- Off-limits protections and native sandbox limits remain enforced. Commands already started can finish after expiry.

Offline tests cover expiry, revocation, pending approvals, command parsing, invalid durations, audit failure, and off-limits denial. Live Telegram behavior has not been qualified by these tests.
