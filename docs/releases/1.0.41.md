# Overlord Bridge 1.0.41

- Free project workers obtain a validated task plan before project actions. Only update_plan is offered during a bounded three-attempt planning phase; unexpected file/command calls are not executed. The accepted plan seeds existing memory across context trimming. Answer-only tasks bypass planning.
- Default source reads return a 6,000-character page from the beginning. Previously a 24,000-character result could consume half the worker history budget and evict useful context after only a couple of reads. Explicit larger reads remain available.
- Source paging reports line/column continuation positions and total line count. Long lines can be read completely without repeating or dropping text.
- Missing command errors identify the required code or command parameter.
- Model request timing logs identify the attempted model and HTTP outcome without logging prompt content or keys.

The observed 1.0.40 worker repeatedly skipped optional planning and filled its context with large source reads before creating a queue test. These changes make the startup contract explicit and reduce source-context churn. GUI continuation changes remain separate from this harness release.

Validation: 189 focused tests passed; canonical checks pending integration.
