# Overlord Bridge 1.0.70

Groq joins the shared free chat/worker pool with GPT-OSS 120B and 20B, existing local tools, provider-wide request/token backoff, configurable pacing and explicit opt-in. Settings > API keys provides a masked Groq key field and a model-catalog key test; the panel scrolls to keep all provider settings reachable. Create a key at https://console.groq.com/keys and use a Free-plan account. Paid accounts may be billed. Overlord cannot verify account billing eligibility or promise unlimited free capacity.

Workers now retain their pending request, task and context while temporary provider quotas or service outages recover. Waiting is cooperative, cancellable through /stop, and refreshes provider settings so a newly saved key can help an already waiting worker. Foreground chat remains bounded. Missing keys, authorization errors, invalid requests, empty replies and truncated tool responses do not cause indefinite capacity waiting. Set OVERLORD_FREE_WORK_WAIT_FOR_CAPACITY=0 to keep the previous bounded behavior. An active wait does not survive bridge shutdown/restart; persistent resumption is on the roadmap.

Cloudflare Workers AI and Mistral are added to ROADMAP.md with explicit free-entitlement, quota and project-work qualification requirements.

Sources: https://console.groq.com/docs/openai ; https://console.groq.com/docs/tool-use/overview ; https://console.groq.com/docs/rate-limits
