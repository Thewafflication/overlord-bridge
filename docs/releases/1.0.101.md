# Overlord 1.0.101

Reject the observed alternate-index bypass before worker command/Python tools
execute. WSH used GIT_INDEX_FILE with an empty index to work around ownership
protection, producing a commit recording 458 unrelated file deletions. The files
were still on disk; origin/master remained unchanged. The damaged commit was
preserved under refs/heads/codex/monitor-wsh-damaged-index-3df90a1 and the prior
branch tip restored by soft reset, with index and edited-header bytes unchanged.
No hard reset, checkout, deletion or project implementation was performed.

Five focused checks cover the observed CMD form, PowerShell assignment, two
Python subprocess/environment forms and ordinary Git commit compatibility.
This rejects the literal known bypass, including case variants. It does not
sandbox constructed variable names, alternate Git databases or arbitrary code.
Free mode and independent acceptance checks remain unchanged.

The bridge was found offline with no shutdown request and no installed Python
process; its exit cause is unknown. This release does not claim to fix an
unreproduced runtime exit. Schedule definitions and sessions are preserved during
the signed installation and normal restart.
