# Overlord Bridge 1.0.24

- The Windows console displays a readable latest-activity summary. Detailed logs are collapsed initially and can be shown or hidden without losing incoming log text.
- Telegram renders explicitly labelled log/output blocks as native expandable quotes. Plain answers, findings, and requested code stay outside those blocks; embedded HTML in logs is escaped.
- All brains and workers receive instructions to lead with the outcome and put verbose diagnostics in log blocks. Token usage has a short summary with labelled expandable counters; provider fallback diagnostics are expandable.
- Brain replies are delivered together at turn completion, preserving log blocks across streamed chunks. Partial responses are delivered if interrupted. Telegram chunking accounts for emoji length.

Offline checks cover presentation, expandable Telegram payloads, escaping, chunk limits, console log toggling and hidden collection, existing turn control, and token reporting. Live Telegram client rendering has not been qualified by these tests.
