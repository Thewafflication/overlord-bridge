# Overlord Bridge 1.0.67

An inaccessible Windows source file could crash an entire free-worker run before the model received a tool result. This occurred during scheduled tcc_package work when Windows returned error 1920 while checking a Makefile.

read_file now returns a structured file_unreadable result for operating-system failures during file inspection or reading. The worker can select accessible source or report the blocker instead of crashing. Existing missing-file and permission restrictions remain in effect.

Regression tests cover both metadata and read failures and verify that the same worker can successfully read another file afterward.

Validation: 139 focused worker tests passed. Canonical syntax/inventory, wheel build and full offline suite passed (1,392 tests, one skip). The actual Windows error-1920 file returns a recoverable tool result.
