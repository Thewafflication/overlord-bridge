# Overlord Bridge 1.0.22

- Routine command auto-approval is enabled by default for shared bridge approval requests. The bounded allowlist covers Git inspection, standard Make build/test/check targets, pytest, npm build/test/check/lint, and common CMake/CTest checks in the supplied workspace.
- The filter checks the actual structured command rather than its display description. Unknown options, publishing/install/destructive commands, shell chains, expansions, redirection, and paths outside the workspace continue to require approval. Build and test commands trust the project's existing recipes.
- `/permissions safe off` disables the policy for the running bridge; `safe on` restores it. `/permissions` reports the current state. Timed full access and exact-action grants remain separate controls.
- Off-limits checks and decision auditing remain in force. Recognized shell wrappers, including standard Windows system shell paths, are inspected; encoded commands and arbitrary executable paths require approval.

Offline tests cover allowed commands, unsafe variants, shell wrappers, workspace containment, policy toggles, audit failures, and existing permission controls. Live Telegram behavior has not been qualified by these tests.
