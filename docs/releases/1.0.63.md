# Overlord Bridge 1.0.63

Projects and Documents now appear as removable defaults in Settings > Projects > Folders containing projects. Saving the list respects removals, including an empty list, instead of silently adding those folders back to project discovery. Existing explicit root lists are respected. The current workspace remains available.

Desktop chat messages now render Markdown headings, bold, italics, lists, inline code, fenced code blocks and HTTP/HTTPS links with visible destinations. Code contents stay literal; saved transcripts retain their original text. Links are displayed without automatic navigation or execution.

Validation: 169 settings and project-discovery tests passed, followed by 38 formatting, console, transport and settings tests including a real Tk widget rendering check.

Full release validation: `tools/check_release_version.py 1.0.63` passed; `tools/check.py all` passed syntax/inventory checks, wheel build and 1,366 tests with one skip.
