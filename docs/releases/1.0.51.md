# Overlord Bridge 1.0.51

- Add a desktop console chat pane with Send/Enter input, shared conversation history, and the same command/turn handling as Telegram. GUI input is echoed to Telegram; outbound replies also appear in the console.
- Queue rapid messages separately, retain unfinished records, and save delivery receipts across bridge restarts. Retry failed delivery without skipping subsequent messages. Failed queue writes retain the typed input.
- Keep transcript history bounded and refresh the display when the transcript rotates. Prevent a console handler's internal TypeError from executing the action twice.

Validation: canonical `python tools/check.py all` passed (syntax/inventory, wheel build, 1,304 tests passed and two skipped). Real Tk tests cover Send, failed input retention, transcript refresh and display bounds. Queue tests cover raw byte offsets, partial records, restart receipts, replacement/truncation and receipt-write failures.

Installed preview verification: the actual installed bridge and Tk console accepted two quick `/help` messages, displayed each owner message once and both command replies, and persisted receipts with no pending requests. Mirroring records queued outbound messages, not Telegram delivery acknowledgements. A crash between dispatch and receipt persistence may replay that last message.

Version 1.0.50 is skipped because an earlier worker published its tag before completing the feature; that tag remains unchanged.
