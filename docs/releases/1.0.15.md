# Overlord Bridge 1.0.15

- Free models recover from temporary OpenRouter catalog failures on the next turn without restarting the pool.
- Successful zero-price and tool-support admission checks expire after five minutes. Expired checks fail closed if the catalog cannot be fetched or the model is no longer free; the zero-price request ceiling remains enforced on every request.
- Regression tests cover catalog outage recovery, admission caching, paid-price rejection after expiry, and recovery when zero pricing returns.

Backward-compatible 1.x maintenance release.
