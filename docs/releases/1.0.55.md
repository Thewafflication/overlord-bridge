# Overlord Bridge 1.0.55

- Give free/local worker commands a null stdin instead of inheriting the bridge's input stream. A command cannot consume owner console input or wait for input on that stream. Tool descriptions and failure guidance explain the noninteractive contract.
- Preserve explicit shell pipelines, file redirection and program-supplied input. Commands that read directly from stdin receive EOF; Python input prompts report EOFError instead of waiting for a response.

Reproduced before the fix: a worker's `sys.stdin.read()` consumed a line intended for its parent process, leaving the parent with no input. Regression checks cover direct Python, shell Python, Windows PowerShell, prompt failure and an explicit input pipeline.

Validation: canonical syntax/inventory, wheel build and full suite passed with 1,320 tests and one skip. The four initial input-isolation/prompt regressions passed; the full suite also verifies explicit pipeline input.

Installed verification: Windows and Linux release CI passed. The signed package verified and installed successfully, and its worker matches the tested source. The installed worker read EOF while its parent retained the complete supplied console-input line.
