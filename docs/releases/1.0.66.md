# Overlord Bridge 1.0.66

Windows package upgrades and removal/reinstallation now preserve `run/scheduled-tasks.json` alongside durable settings, session pins and worker reports. Transient service-control files remain excluded. Linked schedule state is rejected instead of being copied into a replacement installation.

Scheduled prompts now wait for background workers as well as the foreground turn. When several project schedules become due together, the next project waits for existing work to finish instead of starting a burst of competing workers. Overdue intervals still coalesce into one run; manual chat and worker controls remain available.

Regression coverage includes schedule preservation through repeated state save/restore, transient-state exclusion and scheduled-turn deferral while a background project worker is active.

Validation: canonical syntax/inventory checks and wheel build passed; full offline suite passed 1,388 tests with two skips. Final targeted lifecycle/scheduler checks passed 27 tests, including rejection of a linked schedule directory.
