# Overlord Bridge 1.0.32

- Worker command timeouts terminate the owned Windows process tree before draining output. POSIX tool commands use an owned process group for equivalent cleanup. Output draining after timeout has a five-second bound, so inherited pipes cannot hang a turn indefinitely.
- Preserve buffered command output across timeouts, and log when timeout cleanup begins.
- list_files accepts a project-relative directory path and filename pattern, such as path=modules and pattern=*.py. It prunes generated, dependency, secret and linked directories during traversal; worker prompts recommend targeted discovery over recursive shell listings.

Validation includes a real timed-out process with a child inheriting its output pipe, a permanently open pipe simulation, and targeted discovery with verification that generated folders were not traversed. The observed live turn required /stop because its old timeout path had already orphaned PowerShell.

Full offline validation: syntax checks and wheel build passed; 1,159 tests passed and one skipped. The old orphaned PowerShell required operator cleanup from an elevated shell.
