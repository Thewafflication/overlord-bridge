# Agent task workflow

Read PROJECT-WORK.md before choosing or resuming work. Use the shared
[WSP agent prompts](wsp/processes/agent-tasks-template.md) for selection,
execution, continuation and closure.

For this repository, ordinary project coding runs only for owner-directed work
or a demonstrated harness defect. Scheduled-project monitoring follows the
durable audit cursor and the original project exclusions. Keep normal project
implementation in its Overlord worker.

When blocked, record the failed command, actual exit/output, current diff and
next discriminating experiment in the task handoff. When closing, verify the
final source, required checks, owned commit and authorized publication evidence.
